## Demonstration of Static member and static methods

```
class HondaCity{
  static long price = 10; 
  int a, b; 

  static double onRoadPrice(String city){
    switch (city) {
      case "Delhi":
        return  price+price*0.1;
        // break;

        case "Mumbai":
          return price+price*0.2;
      default:
        return  price;
        // break;
    }
  }
}
public  class Static {
 
  public  static void main (String args []){
     HondaCity car1 = new HondaCity();
     System.out.println(car1.onRoadPrice("Mumbai"));
  }
}

## Student Challenge : write method for generating rollNo of student within the class without using main method...
```
import  java.lang.*;
import java.time.LocalDate;

class Student{
  private String rollNo;

  private  static  int count = 1;

  // Method for generating roll number of a student directly inside the class without using the main method...
  private  static String  generateRollNo(){
    LocalDate d = LocalDate.now();
    String rn = "UNIV-"+(d.getYear()-6)+"-"+count;
    count++;
    return  rn;
  }
  public  Student(){
    rollNo = generateRollNo();
  }

  public  String getRollNo(){
    return  rollNo;
  }
}

public class StudentChallenge{
  public  static void main(String args []){
    Student s1 = new Student();
    Student s2 = new Student();
    Student s3 = new Student();
    Student s4= new Student();
    System.out.println(s1.getRollNo());
    System.out.println(s2.getRollNo());
    System.out.println(s3.getRollNo());
    System.out.println(s4.getRollNo());
  }
}
