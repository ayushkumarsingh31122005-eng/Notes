## Demonstration of Inner class...
```

//  Declared Outer class
class Outer{
  int x = 90;
  // Declared Inner class
   class Inner{
    int y = 80;
    // Declared Inner Method
    public void innerDisplay(){
      System.out.println("INner class : "+ x+" "+y);
    }
   }
   // Declared outer method
   public void outerDisplay(){
    // made object of inner class
    Inner i = new Inner();
    i.innerDisplay();
    System.out.println(i.y);
   }
 }

// Main method
 public class NestedInner{
  public  static void main(String args []){
    // making object of outer class...
    Outer o =  new Outer();
    o.outerDisplay();

    // making object of Inner class...
    Outer.Inner  oi = new Outer().new Inner();
    oi.innerDisplay();
    
  }
 }
```

### Demonstration to LocalInner classes...
```
class Outer {
  public  void display(){
    class Inner{
      public  void show(){
        System.out.println("Hello");
      }
    }
    Inner i = new Inner();
    i.show();
  }
}

public class LocalInner
{
  public static void main(String args []){

    Outer o = new Outer();
    o.display();
  }
}
```
