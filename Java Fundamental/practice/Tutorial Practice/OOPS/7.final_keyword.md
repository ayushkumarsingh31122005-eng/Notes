```

  //first way of initilization of final var.. directly inside the class...

    x = 90;
  }
```

## We can not override the final method ...
```
class Test {
  public  final void show(){
    System.out.println("Hello");
  }
}

class Test1 extends  Test{
  // this is not allowed  : we cannot override the final method in subclass or anyWhere...
  public  void  show(){}


}
```
