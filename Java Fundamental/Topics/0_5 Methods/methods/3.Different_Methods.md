



# 26. Static Methods

A method declared with `static` belongs to the class rather than to a particular object.

Example:

```java
class Calculator {

    static int add(int a, int b) {
        return a + b;
    }
}
```

You can call it using the class name:

```java
int result = Calculator.add(10, 20);
```

Conceptually:

```text
Calculator
     │
     └── static add()
```

Oracle's documentation describes static methods as class methods and recommends invoking them using the class name.

---

# 27. Instance Methods

A method without `static` is generally an **instance method**.

Example:

```java
class Student {

    String name;

    void displayName() {
        System.out.println(name);
    }
}
```

To call it:

```java
Student s = new Student();

s.name = "Rahul";

s.displayName();
```

Here:

```java
s.displayName();
```

calls an instance method on object `s`.

---

# 28. Static vs Instance Methods

| Static method                                  | Instance method                                 |
| ---------------------------------------------- | ----------------------------------------------- |
| Belongs to class                               | Belongs to object/instance                      |
| Uses `static`                                  | No `static`                                     |
| Can be called using class name                 | Usually called using object reference           |
| Does not have an ordinary `this` reference     | Has an associated `this` reference              |
| Cannot directly access instance fields/methods | Can directly access accessible instance members |

Example:

```java
class Test {

    static void staticMethod() {
        System.out.println("Static");
    }

    void instanceMethod() {
        System.out.println("Instance");
    }
}
```

Calling:

```java
Test.staticMethod();

Test obj = new Test();
obj.instanceMethod();
```

# 29. The `main()` Method

A Java program commonly begins execution through a `main` method.

A familiar form is:

```java
public static void main(String[] args) {
}
```

Breakdown:

```text
public
  ↓
accessible entry-point declaration

static
  ↓
can be invoked without first creating an object

void
  ↓
returns no value

main
  ↓
method name

String[] args
  ↓
array parameter
```

The exact rules for candidate `main` methods have evolved in newer Java releases; the Java SE 25 specification broadened the accepted forms beyond the traditional `public static void main(String[])`.

For beginner code, however, you will normally continue to encounter:

```java
public static void main(String[] args)
```

# 30. Method Overloading

Java allows multiple methods to have the same name if their **parameter lists differ**.

This is called **method overloading**.

Example:

```java
static int add(int a, int b) {
    return a + b;
}

static int add(int a, int b, int c) {
    return a + b + c;
}
```

Now:

```java
add(10, 20);
```

calls:

```java
add(int, int)
```

while:

```java
add(10, 20, 30);
```

calls:

```java
add(int, int, int)
```

---

# 31. Overloading by Different Parameter Types

```java
static void print(int x) {
    System.out.println("Integer");
}

static void print(double x) {
    System.out.println("Double");
}

static void print(String x) {
    System.out.println("String");
}
```

Calls:

```java
print(10);
print(10.5);
print("Java");
```

The compiler determines which overloaded method is applicable.

# 32. Return Type Alone Cannot Overload a Method

This is **not valid**:

```java
static int test() {
    return 10;
}

static double test() {
    return 10.5;
}
```

Why?

Both methods have the same method name and parameter list:

```text
test()
```

The return type is not enough to distinguish overloaded methods.

Java's method-overloading rules use the method signature/parameter information, not merely the return type.

---

# 33. Method Signature

For Java's method-overloading rules, the **method signature** consists of:

```text
method name + parameter types
```

Example:

```java
add(int, int)
```

and:

```java
add(double, double)
```

are different signatures.

These are not different signatures merely because of return types:

```java
int add(int a, int b)
double add(int a, int b)
```

# 34. Method Overloading vs Method Overriding

These are different concepts.

### Overloading

Usually occurs within the same class:

```java
add(int, int)
add(double, double)
```

Same name, different parameter lists.

### Overriding

Occurs when a subclass provides a new implementation of an inherited instance method.

Example:

```java
class Animal {

    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {

    @Override
    void sound() {
        System.out.println("Bark");
    }
}
```

Here `Dog` overrides `sound()`.

You will study overriding in detail with inheritance and polymorphism.

# 35. Recursive Methods

A method can call itself.

This is called **recursion**.

Example:

```java
static void countDown(int n) {

    if (n == 0) {
        return;
    }

    System.out.println(n);

    countDown(n - 1);
}
```

Call:

```java
countDown(5);
```

Execution:

```text
countDown(5)
    ↓
countDown(4)
    ↓
countDown(3)
    ↓
countDown(2)
    ↓
countDown(1)
    ↓
countDown(0)
```

The condition:

```java
if (n == 0)
```

is the **base case**.

Without an appropriate base case, recursion can continue until the program encounters a stack-related failure such as `StackOverflowError`.
