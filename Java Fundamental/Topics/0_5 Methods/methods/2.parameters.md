# 12. Parameters

A **parameter** is a variable declared in a method declaration that receives an input.

Example:

```java
static int add(int a, int b) {
    return a + b;
}
```

Here:

```java
int a
int b
```

are parameters.

When calling:

```java
add(10, 20);
```

the values `10` and `20` are supplied to those parameters.

---

# 13. Arguments vs Parameters

This distinction is important.

### Parameter

The variable declared in the method:

```java
static int add(int a, int b)
```

`a` and `b` are **parameters**.

### Argument

The actual values supplied during the method call:

```java
add(10, 20);
```

`10` and `20` are **arguments**.

```text
Method declaration:

add(int a, int b)
        ↑      ↑
    parameters


Method call:

add(10, 20)
    ↑    ↑
 arguments
```

# 14. Method Invocation

Calling a method is technically called **method invocation**.

Example:

```java
greet();
```

Here:

```java
greet()
```

is a method invocation.

For a static method:

```java
ClassName.methodName();
```

Example:

```java
Math.sqrt(25);
```

For an instance method:

```java
object.methodName();
```

Example:

```java
String name = "Java";

int length = name.length();
```

The Java Language Specification has detailed rules for how method invocation is resolved and executed.

A method doesn't have to receive input.


Call it:


```java
greet();
```


# 20. Four Common Method Forms

You should understand these four combinations:

| Parameters | Return value | Example                 |
| ---------- | ------------ | ----------------------- |
| No         | No           | `void greet()`          |
| Yes        | No           | `void print(int n)`     |
| No         | Yes          | `int getNumber()`       |
| Yes        | Yes          | `int add(int a, int b)` |

Examples:

### 1. No parameter, no return

```java
static void greet() {
    System.out.println("Hello");
}
```

### 2. Parameter, no return

```java
static void printNumber(int n) {
    System.out.println(n);
}
```

### 3. No parameter, return

```java
static int getNumber() {
    return 10;
}
```

### 4. Parameter, return

```java
static int square(int n) {
    return n * n;
}
```

These are useful categories for learning, but Java does not formally classify methods only into these four types.

# 21. Complete Example

```java
public class Main {

    static int add(int a, int b) {
        int sum = a + b;
        return sum;
    }

    public static void main(String[] args) {

        int result = add(10, 20);

        System.out.println(result);
    }
}
```

Execution:

```text
main()
  ↓
add(10, 20)
  ↓
a = 10
b = 20
  ↓
sum = 30
  ↓
return 30
  ↓
result = 30
  ↓
print 30
```

Output:

```text
30
```

# 22. Local Variables Inside Methods

Variables declared inside a method are called **local variables**.

```java
static int add(int a, int b) {

    int sum = a + b;

    return sum;
}
```

Here:

```java
int sum
```

is a local variable.

It exists only within the method's scope.

You cannot do:

```java
static int add(int a, int b) {

    int sum = a + b;

    return sum;
}

public static void main(String[] args) {

    System.out.println(sum); // ERROR
}
```

`sum` is not visible inside `main()`.

---

# 23. Scope of Method Parameters

Parameters are also local to the method.

```java
static void print(int number) {
    System.out.println(number);
}
```

`number` can be used inside this method.

It cannot directly be accessed from another method:

```java
static void print(int number) {
    System.out.println(number);
}

static void test() {
    System.out.println(number); // ERROR
}
```

# 24. Java Is Pass-by-Value

This is one of the most important facts about Java:

> **Java is always pass-by-value.**  
 * This mean : When you pass an argument to a method in Java, the method receives a copy of the value, not the original variable itself.

For primitive values, this is straightforward.

```java
static void change(int x) {
    x = 100;
}

public static void main(String[] args) {

    int a = 10;

    change(a);

    System.out.println(a);
}
```

Output:

```text
10
```

Why?

```text
a
│
└── 10

change(a)

x
│
└── 10
```

`x` receives a copy of the value.

Changing `x` does not change `a`.

# 25. Passing Objects to Methods

This becomes more interesting with objects and arrays.

Consider:

```java
static void update(int[] arr) {

    arr[0] = 100;
}

public static void main(String[] args) {

    int[] numbers = {1, 2, 3};

    update(numbers);

    System.out.println(numbers[0]);
}
```

Output:

```text
100
```

Java still passes by value.

The value being copied is the **reference value**.

Conceptually:

```text
numbers
   │
   │ reference
   ↓
┌─────────────┐
│ 1 │ 2 │ 3   │
└─────────────┘
       ↑
       │
      arr
```

Both variables contain reference values that refer to the same array object.

Therefore:

```java
arr[0] = 100;
```

modifies the same array object.

But Java does **not** pass the variable itself by reference.
