## There are two different uses of variable arguments in your program, and they are independent of each other.

### 1. main(String ...args)

```

public static void main(String ...args)
```
* This means:

* The main() method can receive a variable number of String arguments.

#### It is equivalent to:
```
public static void main(String[] args)
```
#### So Java allows both:
```
public static void main(String[] args)
```
and
```
public static void main(String... args)
```
#### For example, when Java starts your program, it can conceptually call:
```
main(new String[]{"hello", "world"});
```
## Those values are called command-line arguments.

#### However, you did not need to use varargs in main() just because max() uses varargs. They are completely separate.
