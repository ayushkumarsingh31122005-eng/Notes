# 8. Mathematical Operations (`Math` Class)

Java provides standard math operations through the `Math` utility class.

### `Math.pow()` (Exponentiation)
Java does not have a dedicated exponentiation operator like `**`.

```java
// Math.pow(base, exponent) -> returns a double
double result = Math.pow(2.0, 3.0); // 2³ = 8.0
```

**Type Casting with `Math.pow()`:**
Since `Math.pow()` always returns a `double`, an explicit cast is required if an integer result is needed.
```java
int result = (int) Math.pow(2, 3); // result is 8
```
> **Warning:** Casting `double` to `int` discards the fractional part (truncates); it does *not* round. `(int) 8.9` becomes `8`.

### Other Useful `Math` Methods

| Method | Purpose | Example | Result |
|---|---|---|---:|
| `Math.sqrt(x)` | Square root | `Math.sqrt(100)` | `10.0` |
| `Math.max(x, y)` | Larger value | `Math.max(10, 20)` | `20` |
| `Math.min(x, y)` | Smaller value | `Math.min(10, 20)` | `10` |
| `Math.abs(x)` | Absolute value | `Math.abs(-45)` | `45` |
| `Math.round(x)` | Rounds to nearest `long` | `Math.round(3.6)` | `4` |
