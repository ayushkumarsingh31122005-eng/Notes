# . Important Rules to Remember

1. A method is declared inside a class or interface.
2. A method has a name.
3. A method can have zero or more parameters.
4. A method has a result type; `void` means it does not return a value.
5. A non-`void` method must return an appropriate value on every reachable normal completion path.
6. A method is executed when it is invoked.
7. Parameters receive values from arguments.
8. Java uses pass-by-value.
9. Static methods belong to the class.
10. Instance methods operate in the context of an object.
11. Methods can be overloaded.
12. Return type alone cannot overload a method.
13. A `final` method cannot be overridden.
14. An `abstract` method does not provide an implementation in its declaration.
15. A method can call another method.
16. A method can call itself through recursion. 
17. Local variables belong to the scope in which they are declared.
18. A method can return primitive values, object references, arrays, and other reference values.
19. Methods are fundamental to code reuse, decomposition, abstraction, and maintainability.
