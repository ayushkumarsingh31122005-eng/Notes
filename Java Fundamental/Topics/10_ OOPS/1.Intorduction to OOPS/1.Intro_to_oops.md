# 🌟 What is OOP?

Imagine you want to build a house. You don't just start putting bricks together randomly. First, an architect draws a **blueprint** (a design) on paper. Then, using that blueprint, builders construct the **actual physical house**. You can even build multiple houses from the same blueprint!

In Java:
*   **Class** = The Blueprint 📝
*   **Object** = The Actual House 🏠

**Object-Oriented Programming** is a way of writing computer programs using "Objects" to represent real-world things. It helps keep our code organized, reusable, and easy to understand.

### 🎨 Visualizing Class vs. Object

```text
       [ CLASS (Blueprint) ]                  [ OBJECTS (Real things) ]
      +---------------------+               +-------------------------+
      |  Car                |               |  My Car:                |
      |---------------------|   Creates     |  - Red, Toyota          |
      |  Properties:        | ------------> +-------------------------+
      |  - color            |               
      |  - brand            |               +-------------------------+
      |                     |   Creates     |  Your Car:              |
      |  Behaviors (Actions)| ------------> |  - Blue, Honda          |
      |  - drive()          |               +-------------------------+
      |  - stop()           |
      +---------------------+
```

### 💻 Code Example: Class and Object

```java
// 1. We create the Blueprint (Class)
class Car {
    // Properties (Data)
    String color;
    String brand;

    // Behavior (Action/Method)
    void drive() {
        System.out.println("The " + color + " " + brand + " is driving!");
    }
}

// 2. Main class to run the program
public class Main {
    public static void main(String[] args) {
        // We create the actual Object from the blueprint using 'new' keyword
        Car myCar = new Car(); 
        myCar.color = "Red";
        myCar.brand = "Toyota";
        
        // Let's use the object!
        myCar.drive(); // Output: The Red Toyota is driving!
    }
}
```
