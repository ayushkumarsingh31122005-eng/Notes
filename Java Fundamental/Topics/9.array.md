# 📦 1. What is an Array?
Imagine you want to store the ages of 5 friends. You *could* create 5 separate variables:
`int age1 = 20;`, `int age2 = 22;`, `int age3 = 25;` ... and so on.

But what if you have 100 friends? Creating 100 variables is a nightmare! 
This is where **Arrays** come in.

An **Array** is a container object that holds a fixed number of values of a **single type** (like only integers, or only text). Think of it like a medicine pillbox with separate compartments for each day.

### 🎨 Visual Diagram of an Array
Let's say we have an array of 5 numbers: `[10, 20, 30, 40, 50]`

```text
Array Name: 'numbers'

 Value:   [  10  ] [  20  ] [  30  ] [  40  ] [  50  ]
          -----------------------------------------
 Index:      0       1       2       3       4
```
**Crucial Rule:** In Java, counting starts at **0**. The first item is at index 0, not index 1!

## 🛠️ 2. Methods of Creating an Array

There are two main ways to create an array in Java.

### Method A: Step-by-Step (Declaration & Instantiation)
Use this when you know *how many* items you want to store, but you don't know the exact values yet.

```java
// 1. Declare the array (tell Java it's an array of integers)
int[] ages; 

// 2. Instantiate the array (tell Java to make room for 5 items)
ages = new int[5]; 

// We can combine these into one single line like this:
int[] scores = new int[5];
```
*(Note: When you do this, Java automatically fills the array with default values. For `int`, it fills it with `0`s).*

### Method B: Array Literal (Direct Initialization)
Use this when you *already know* the values you want to put in the array right from the start.

```java
// Create an array and fill it with actual values immediately
String[] fruits = {"Apple", "Banana", "Mango", "Orange"};
```

## 🔍 3. Accessing Elements in an Array

To read or change a value inside the array, you use its **Index** inside square brackets `[]`.

### Example Code: Accessing Data
```java
public class ArrayDemo {
    public static void main(String[] args) {
        int[] prices = {100, 200, 300, 400};

        // Reading values
        System.out.println("First price: " + prices[0]); // Outputs 100
        System.out.println("Third price: " + prices[2]); // Outputs 300

        // Changing a value
        prices[1] = 250; // Changes the second item from 200 to 250
        System.out.println("Updated second price: " + prices[1]);
    }
}
```

## 🔄 4. Loops and Arrays: The Perfect Match

If you want to print all 100 items in an array, you don't want to write `System.out.println()` 100 times. We use **Loops** to go through (traverse) the array automatically.

### A. The `for` Loop
The traditional `for` loop is great when you need to know the exact index (position) of the item while you are looking at it.

**Syntax & Example:**
```java
int[] numbers = {10, 20, 30, 40};

// i starts at 0. Loop runs as long as i is less than the array's length.
for (int i = 0; i < numbers.length; i++) {
    System.out.println("Element at index " + i + " is " + numbers[i]);
}
```
*(Note: `numbers.length` is a handy tool Java gives us to automatically find out how big the array is!)*

### B. The Enhanced `for-each` Loop (The Easiest Way!)
Introduced in newer versions of Java, this loop is specifically designed to go through arrays quickly without worrying about index numbers.

**Syntax & Example:**
```java
String[] names = {"Alice", "Bob", "Charlie"};

// Read as: "For each String 'name' inside the 'names' array..."
for (String name : names) {
    System.out.println("Hello, " + name);
}
```
*Best Use:* When you just want to read all elements from start to finish and you don't care about the index numbers.

### C. The `while` Loop
The `while` loop checks a condition first, and if it's true, it runs the code. Unlike the `for` loop, we have to manually create and increase our counter variable.

**Syntax & Example:**
```java
int[] scores = {85, 90, 95};
int counter = 0; // Our index tracker

while (counter < scores.length) {
    System.out.println("Score: " + scores[counter]);
    counter++; // CRITICAL: Don't forget to increase the counter, or it loops forever!
}
```
