# 🚀 Mastering Java Loops


## 🎯 What is a Loop?


 **Loop** is a tool that tells the computer to **repeat a block of code multiple times** as long as a specific condition is true. 

Why do we need them? Imagine your boss asks you to print "Hello" 100 times. Writing `System.out.println("Hello");` 100 times is boring and bad coding. Instead, you write it **once** inside a loop, and the computer does the hard work!

There are 4 main types of loops in Java:
1. `while` loop
2. `do-while` loop
3. `for` loop
4. `for-each` loop

Let's dive into each one!

---

## 1️⃣ The `while` Loop

**Best used when:** You don't know exactly how many times you need to loop, but you know when you want to stop.

### How it works (Visual Diagram):
```text
      [ Start ]
          |
    +------>[ Is Condition TRUE? ] ---> NO ---> [ Exit Loop ]
    |             |
    |            YES
    |             |
    |      [ Run the Code ]
    |             |
    +-------------+ (Go back and check again)
```

### Syntax:
```java
while (condition_is_true) {
    // code to be executed
}
```

### Example Code:
```java
public class WhileLoopExample {
    public static void main(String[] args) {
        int count = 1; // Start counting from 1

        // Loop as long as count is less than or equal to 3
        while (count <= 3) { 
            System.out.println("Current count is: " + count);
            count++; // This means count = count + 1 (very important so the loop eventually stops!)
        }
    }
}
/* Output:
Current count is: 1
Current count is: 2
Current count is: 3
*/
```

---

## 2️⃣ The `do-while` Loop

**Best used when:** You want the code to run **at least one time**, no matter what. It executes the code first, and *then* checks the condition.

### How it works (Visual Diagram):
```text
      [ Start ]
          |
    [ Run the Code (At least once!) ]
          |
    [ Is Condition TRUE? ] ---> NO ---> [ Exit Loop ]
          |
         YES
          |
    (Go back to run code)
```

### Syntax:
```java
do {
    // code to be executed
} while (condition_is_true);
```

### Example Code:
```java
public class DoWhileExample {
    public static void main(String[] args) {
        int count = 10; 

        do {
            // Even though 10 is NOT less than 3, this code will run ONCE!
            System.out.println("Current count is: " + count);
            count++; 
        } while (count < 3); 
    }
}
/* Output:
Current count is: 10
*/
```

---

## 3️⃣ The `for` Loop

**Best used when:** You know **exactly** how many times you want the loop to run. It keeps all the loop rules (start, condition, update) in one neat line.

### Syntax:
```java
for (initialization; condition; update) {
    // code to be executed
}
```
* **Initialization:** Where does the loop start? (e.g., `int i = 1`)
* **Condition:** When should the loop stop? (e.g., `i <= 5`)
* **Update:** How should we step forward? (e.g., `i++` which adds 1)

### Example Code:
```java
public class ForLoopExample {
    public static void main(String[] args) {
        
        // Starts at 1, runs while i is <= 3, adds 1 each time
        for (int i = 1; i <= 3; i++) {
            System.out.println("Printing document page: " + i);
        }
    }
}
/* Output:
Printing document page: 1
Printing document page: 2
Printing document page: 3
*/
```

---

## 4️⃣ The `for-each` Loop (Enhanced For Loop)

**Best used when:** You want to easily go through a list or an array of items. You don't have to worry about counting!

### Syntax:
```java
for (DataType item : arrayName) {
    // code using 'item'
}
```

### Example Code:
```java
public class ForEachExample {
    public static void main(String[] args) {
        // We have a list of names
        String[] friends = {"Alice", "Bob", "Charlie"};

        // Read as: "For each String 'name' in the 'friends' array..."
        for (String name : friends) {
            System.out.println("Hello, " + name + "!");
        }
    }
}
/* Output:
Hello, Alice!
Hello, Bob!
Hello, Charlie!
*/
```

## ♾️ The Danger Zone: Infinite Loops

**What is it?** An infinite loop is a loop that **never stops running**. 
This usually happens by mistake when the programmer forgets to update the counter, or the condition is always true. It will crash your program or freeze your computer!

### Visualizing an Infinite Loop:
```text
      [ Start ]
          |
    +------>[ Condition is ALWAYS TRUE ] 
    |             |
    |      [ Run the Code ]
    |             |
    +-------------+ (Trapped forever!)
```

### Example of a Mistake (DO NOT RUN THIS):
```java
public class InfiniteLoopExample {
    public static void main(String[] args) {
        int count = 1;

        while (count > 0) {
            System.out.println("I am trapped forever!");
            // Oops! We forgot to change the value of 'count'. 
            // 1 will ALWAYS be greater than 0!
        }
    }
}
```
*Tip to avoid this:* Always double-check that your loop has a way to reach an end condition!

## 📝 Summary Cheat Sheet

| Loop Type | When to use it? |
|-----------|-----------------|
| **`while`** | When you don't know the exact number of loops, but have a stopping condition. |
| **`do-while`** | When you need the code to run **at least one time**, guaranteed. |
| **`for`** | When you know **exactly** how many times to run the loop. |
| **`for-each`**| When you want to easily read every item in an array or list. |
