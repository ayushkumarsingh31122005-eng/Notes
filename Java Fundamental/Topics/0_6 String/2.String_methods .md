
# ☕ Java String Methods


> **Important Reminder:** Strings in Java are **0-indexed**. This means counting always starts at `0`, not `1`.
> 
> ```text
> String: "J A V A"
> Index:   0 1 2 3
> ```

---

## 1. `int length()` 📏
**What it does:** It counts how many characters (letters, numbers, spaces) are in the String and returns that count as an integer (`int`).
**Visual:** "JAVA" has 4 letters. `length()` returns 4.

```java
String word = "Hello";
int size = word.length(); 
System.out.println(size); // Output: 5
```

---

## 2. `String toLowerCase()` & `String toUpperCase()` 🔠
**What they do:** They change the case of the letters. `toLowerCase()` makes everything small, and `toUpperCase()` makes everything CAPITALIZED. 

```java
String text = "Java is FUN!";

System.out.println(text.toLowerCase()); // Output: java is fun!
System.out.println(text.toUpperCase()); // Output: JAVA IS FUN!
```

---

## 3. `String trim()` ✂️
**What it does:** It removes empty spaces from the **beginning** and the **end** of your String. It does *not* remove spaces in the middle.

**Visual:**
`[space][space]Hello[space]World[space]` ➔ `Hello[space]World`

```java
String dirtyInput = "   Hello World    ";
String cleanInput = dirtyInput.trim();

System.out.println("'" + cleanInput + "'"); // Output: 'Hello World'
```

---

## 4. `String substring(int begin)` & `String substring(int begin, int end)` 🍰
**What they do:** They cut out a specific slice (a sub-string) from your main String.
*   **1 Parameter (`begin`):** Cuts from the `begin` index all the way to the end.
*   **2 Parameters (`begin`, `end`):** Cuts from the `begin` index up to the `end` index **(but does NOT include the character at the `end` index)**.

**Visual:**
```text
  0   1   2   3   4   5   6
| b | u | i | l | d | e | r |

substring(2)      ➔ "ilder" (from index 2 to end)
substring(0, 5)   ➔ "build" (from index 0 up to 4, stops before 5)
```

```java
String word = "builder";
System.out.println(word.substring(2));    // Output: ilder
System.out.println(word.substring(0, 5)); // Output: build
```

---

## 5. `String replace(char old, char new)` 🔄
**What it does:** It searches the String for the `old` character and replaces every single occurrence with the `new` character.

```java
String word = "banana";
String fixedWord = word.replace('a', 'o'); // Swap all 'a's with 'o's

System.out.println(fixedWord); // Output: bonono
```

---

## 6. `boolean startsWith(String s)` & `boolean endsWith(String s)` 🏁
**What they do:** These are checking methods. They return `true` or `false` based on whether the String starts or ends with the specific text you provide.

```java
String website = "https://www.google.com";

System.out.println(website.startsWith("https")); // Output: true
System.out.println(website.endsWith(".org"));    // Output: false
```

---

## 7. `char charAt(int index)` 🎯
**What it does:** It acts like a sniper. You give it an index number, and it returns the exact single character (`char`) sitting at that position.

**Visual:**
```text
  0   1   2
| C | a | t |
```

```java
String animal = "Cat";
char letter = animal.charAt(1);

System.out.println(letter); // Output: a
```

---

## 8. `int indexOf(String s)` & `int lastIndexOf(String s)` 🔍
**What they do:** They search for text inside your String and return the **index number** where it starts.
*   `indexOf` finds the **first** time it appears (scanning left to right).
*   `lastIndexOf` finds the **last** time it appears (scanning right to left).
*   *Note: If the text is not found, both methods return `-1`.*

**Visual:**
```text
  0   1   2   3   4   5   6
| a | v | a | t | a | r | s |
```

```java
String movie = "avatars";

// Find first 'a'
System.out.println(movie.indexOf("a"));     // Output: 0

// Find last 'a'
System.out.println(movie.lastIndexOf("a")); // Output: 4

// Find 'z'
System.out.println(movie.indexOf("z"));     // Output: -1
```

---

## 9. `boolean equals(String s)` & `boolean equalsIgnoreCase(String s)` 🤝
**What they do:** They compare two strings to see if they have the exact same text.
*   `equals`: Strictly checks text. "A" is not equal to "a".
*   `equalsIgnoreCase`: Checks text but ignores whether letters are capital or small.

> **Pro Tip:** Never use `==` to compare the text of Strings. Always use `.equals()`!

```java
String password = "Secret123";
String input = "secret123";

System.out.println(password.equals(input));             // Output: false
System.out.println(password.equalsIgnoreCase(input)); // Output: true
```

---

## 10. `int compareTo(String s)` ⚖️
**What it does:** It compares two Strings alphabetically (dictionary order).
*   Returns **0** if both strings are exactly the same.
*   Returns a **negative number** if your String comes *before* the other String in the dictionary.
*   Returns a **positive number** if your String comes *after* the other String in the dictionary.

```java
String word1 = "Apple";
String word2 = "Banana";
String word3 = "Apple";

System.out.println(word1.compareTo(word2)); // Output: negative number (because A is before B)
System.out.println(word2.compareTo(word1)); // Output: positive number (because B is after A)
System.out.println(word1.compareTo(word3)); // Output: 0 (They are the same)
```

# 11. Ways to convert Integer to String.
## 1. `String valueOf(int i)` 🪄
**What it does:** This is a very special **static** method. You don't call it on an existing string (like `myString.valueOf()`); you call it on the String *class* itself (`String.valueOf()`). It takes a primitive data type (like an `int`) and transforms it into a String.

**Visual:** Number `100` ➔ Text `"100"`

```java
int score = 100;

// Convert integer 100 to String "100"
String scoreText = String.valueOf(score); 

System.out.println("Your score is: " + scoreText);
```

 ### 12. String concat(String str) ➕
* **What it does:** "Concat" is short for concatenation (linking things together). It adds the str to the very end of your current String.

* **Why we use it:** It does the exact same thing as the + operator. However, some developers prefer concat() when chaining multiple methods together because it reads clearly from left to right.
```
String firstName = "John ";
String lastName = "Doe";

// Using the + operator
String fullName1 = firstName + lastName;

// Using concat()
String fullName2 = firstName.concat(lastName);

System.out.println(fullName2); // Output: John Doe
```
### 13. String repeat(int count) 🔁 (Java 11+)
 * **What it does:** It takes your String and repeats it a specific number of times.
 ```
 String star = "⭐ ";
String border = "-".repeat(20);

System.out.println(border);
System.out.println(star.repeat(5)); // Repeats the star 5 times
System.out.println(border);

/* Output:
--------------------
⭐ ⭐ ⭐ ⭐ ⭐ 
--------------------
*/
 ```
 ## A. `String.format()` 🏗️
**What it does:** This is the most professional way to build a String containing variables. Instead of using a bunch of messy `+` signs to glue text and variables together, you use placeholders (like `%s` for Strings and `%d` for whole numbers) and let Java fill in the blanks!

**Visual Concept:**
`"Hello, my name is [BLANK] and I am [BLANK] years old"`

```java
String name = "Alice";
int age = 25;

// The old, messy way (concatenation)
String greeting1 = "Hello, my name is " + name + " and I am " + age + " years old.";

// The clean, everyday way using format()
String greeting2 = String.format("Hello, my name is %s and I am %d years old.", name, age);

System.out.println(greeting2); 
// Output: Hello, my name is Alice and I am 25 years old.
```

## Advance String Methods


## 14. `String[] split(String regex)` 🪓
**What it does:** This is one of the most powerful methods in Java. It takes a single String and "chops" it into an array of smaller Strings based on a delimiter (like a space, comma, or dash) that you provide.

**Visual:**
```text
String: "Apple,Banana,Mango"
Delimiter: ","

[ "Apple" ]  [ "Banana" ]  [ "Mango" ]
```

```java
String data = "Java-Python-C++-Ruby";
String[] languages = data.split("-"); 

// languages array now holds: ["Java", "Python", "C++", "Ruby"]
System.out.println(languages[1]); // Output: Python
```

---

## 15. `boolean contains(CharSequence s)` 🔎
**What it does:** It checks if a specific sequence of characters exists *anywhere* inside the main String. It's much simpler than using `indexOf` if you only need a Yes/No answer!

```java
String email = "student@university.edu";

System.out.println(email.contains("@"));           // Output: true
System.out.println(email.contains("gmail"));       // Output: false
```

---

## 16. `boolean isEmpty()` vs `boolean isBlank()` 🫙
**What they do:** Both check if a String is empty, but they have one massive difference when it comes to "whitespace" (spaces, tabs, newlines).
* `isEmpty()`: Returns `true` ONLY if the length is exactly `0`.
* `isBlank()`: Returns `true` if the length is `0` OR if the string contains *only* whitespace (Introduced in Java 11).

```java
String emptyString = "";
String spaceString = "   ";

// isEmpty checks length strictly
System.out.println(emptyString.isEmpty()); // true
System.out.println(spaceString.isEmpty()); // false (length is 3!)

// isBlank is smarter about spaces
System.out.println(emptyString.isBlank()); // true
System.out.println(spaceString.isBlank()); // true (it's just empty spaces)
```

---

## 17. `char[] toCharArray()` 🧱
**What it does:** It takes your String and shatters it into an array of individual `char` primitives. This is extremely useful for algorithm questions (like reversing a string or checking for palindromes).

**Visual:**
```text
String: "CODE"  ➔  char[]: [ 'C', 'O', 'D', 'E' ]
```

```java
String word = "Java";
char[] letters = word.toCharArray();

for (char letter : letters) {
    System.out.println(letter);
}
// Output prints J, a, v, a on separate lines.
```

---

## 18. `String replaceAll(String regex, String replacement)` 🎭
**What it does:** In our last lesson, we looked at `replace()`, which swaps basic characters or words. `replaceAll()` is the stronger older sibling. It uses **Regular Expressions (Regex)** to find patterns instead of just exact words. 

*Want to remove ALL numbers from a string? Use Regex!*

```java
String messyData = "My phone number is 555-1234!";

// The regex "\\d" means "any digit (number)"
// This replaces all numbers with a * symbol.
String cleanData = messyData.replaceAll("\\d", "*"); 

System.out.println(cleanData); 
// Output: My phone number is ***-****!
```

---

## 19. `String String.join(CharSequence delimiter, CharSequence... elements)` 🔗
**What it does:** This is the exact opposite of `split()`. It is a static method that takes multiple Strings (or an array) and glues them together, placing a delimiter (like a comma or hyphen) between each one. (Introduced in Java 8).

```java
// Gluing individual words together with a slash
String date = String.join("/", "2024", "10", "31");

System.out.println(date); // Output: 2024/10/31
```

---
## 20. `boolean matches(String regex)` 🛡️
**What it does:** This is your everyday **Validation Tool**. It checks if your String perfectly matches a specific pattern (Regular Expression / Regex). We use this constantly to check if an email looks valid, or if a password contains numbers, without writing 20 lines of `if/else` statements.

```java
String phone = "555-1234";
String letters = "abc-defg";

// The regex "\\d{3}-\\d{4}" means: exactly 3 digits, a dash, and exactly 4 digits.
System.out.println(phone.matches("\\d{3}-\\d{4}"));   // Output: true
System.out.println(letters.matches("\\d{3}-\\d{4}")); // Output: false
```

---

* **Why we use it:** Before Java 11, if we wanted a line of dashes ----------, we had to use a for loop. Now, we can do it in one simple line! It's great for formatting text outputs or drawing borders in the console.
