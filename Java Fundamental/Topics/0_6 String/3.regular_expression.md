# 🌟 What is a Regular Expression?

Imagine you are looking for a specific word in a giant book. You would normally use "Ctrl + F" (Find) to search for exactly that word. 

But what if you want to find **any phone number** in the book? Phone numbers are different, so you can't search for just one. You need a **rule** or a **pattern** like: 
*   "Find exactly 10 digits in a row."

**A Regular Expression (Regex) is simply a sequence of characters that forms a search pattern.** It is a super-powered "Find" tool used to search, edit, or manipulate text and data.

### Visualizing How Regex Works

```text
[ Your Text ] -----> [ Regex Engine ] -----> [ Result ]
"My phone is 12345"    Pattern: "Find digits"    Matches: "12345"
```

## 2. The Java Regex Packages

In Java, to use Regular Expressions, we use a built-in library called `java.util.regex`. 
It has three main classes (think of classes as tools in a toolbox):

1. **`Pattern`**: This is the rule/pattern you create. (The "What are we looking for?")
2. **`Matcher`**: This is the engine that does the searching. (The tool that reads your text and finds matches).
3. **`PatternSyntaxException`**: This tells you if you made a grammar mistake while writing your pattern.

---

## 3. Basic Regex Syntax (The Secret Code)

Regex uses special characters to represent different things. Here is a simple "cheat sheet":

### Character Classes (What character?)
*   `[abc]` : Find one character from the options inside the brackets (a, or b, or c).
*   `[^abc]` : Find any character EXCEPT a, b, or c.
*   `[0-9]` : Find any number from 0 to 9.
*   `[a-zA-Z]` : Find any English letter, uppercase or lowercase.

### Metacharacters (Special rules)
In Java, when we use these inside a String, we have to put **two backslashes (`\`)** in front of them so Java doesn't get confused.
*   `\d` : Any digit (0-9).
*   `\D` : Any NON-digit (letters, symbols).
*   `\s` : Any whitespace (space, tab, new line).
*    `\S`: Not  Space.
*   `\w` : Any word character (letters, digits, or underscore `_`).
*    `\W`: Neither alphabet or digit.    

* But here in java we use "\\"  because java understand single backslash "\" as the beginning of of an escape sequence inside a String.

### Quantifiers (How many times?)
*   `+` : Matches 1 or more times. (e.g., `A+` matches "A", "AA", "AAA")
*   `*` : Matches 0 or more times.
*   `?` : Matches 0 or 1 time.
*   `{n}`: Matches exactly *n* times. (e.g., `\d{10}` means exactly 10 digits).
*   `{X,Y}`: Betweent X and Y times.

## 4. Java Example: Let's Write Some Code!

Let's write a program that checks if a user entered a valid 10-digit phone number.

```java
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class RegexExample {
    public static void main(String[] args) {
        
        // 1. The Text we want to check
        String textToSearch = "Call me at 9876543210 today.";
        
        // 2. Create the Pattern (Rule)
        // \b means "word boundary" (so we don't match 10 digits inside a 15-digit number)
        // \d{10} means exactly 10 digits
        String regexRule = "\b\d{10}\b";
        
        // Compile the rule into a Pattern object
        Pattern pattern = Pattern.compile(regexRule);
        
        // 3. Create the Matcher (The Engine)
        Matcher matcher = pattern.matcher(textToSearch);
        
        // 4. Run the engine and find results!
        System.out.println("Searching for 10-digit phone numbers...");
        
        while (matcher.find()) { // While the engine finds a match
            System.out.println("I found a match: " + matcher.group());
            System.out.println("It starts at index: " + matcher.start());
            System.out.println("It ends at index: " + matcher.end());
        }
    }
}
```

**Output of this code:**
```text
Searching for 10-digit phone numbers...
I found a match: 9876543210
It starts at index: 11
It ends at index: 21
```

## 5. Conected Topics in Java

Did you know you can use Regex directly on Java `String` objects without using Pattern and Matcher? Here are three very useful String methods that use Regex in the background:

### A. `String.matches(regex)`
Checks if the ENTIRE string matches the pattern. Returns `true` or `false`.
```java
String password = "SecretPassword123";
// Does it contain only letters and numbers?
boolean isValid = password.matches("[a-zA-Z0-9]+"); 
```

### B. `String.replaceAll(regex, replacement)`
Replaces all parts of a string that match the regex with something else.
```java
String dirtyText = "I    have   too    many   spaces.";
// Replace 1 or more spaces (\s+) with a single space (" ")
String cleanText = dirtyText.replaceAll("\s+", " ");
// Result: "I have too many spaces."
```

### C. `String.split(regex)`
Splits a string into an array based on a regex pattern.
```java
String fruits = "apple,banana;orange|grape";
// Split by comma, or semicolon, or pipe symbol
String[] fruitArray = fruits.split("[,;|]"); 
```
