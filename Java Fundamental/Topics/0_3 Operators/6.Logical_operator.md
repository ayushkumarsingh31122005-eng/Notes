#  Logical Operators in Java ☕
 ### **Logical Operators** help us combine multiple conditions just like this. They check the conditions and always give us a `boolean` answer: `true` or `false`.

## 2. The Three Main Logical Operators in Java

Here are the three logical operators you will use every day:

| Operator Name | Symbol | What it means in simple English |
| :--- | :---: | :--- |
| **Logical AND** | `&&` | Returns `true` only if **BOTH** conditions are true. |
| **Logical OR** | `\|\|` | Returns `true` if **AT LEAST ONE** condition is true. |
| **Logical NOT** | `!` | Reverses the result. If true, makes it `false`. |

---
### A. Logical AND (`&&`)
Think of `&&` as a strict boss. Both rules must be followed!

**Visual Truth Table:**
| Condition 1 | Operator | Condition 2 | Result |
| :---: | :---: | :---: | :---: |
| ✅ `true` | `&&` | ✅ `true` | **✅ `true`** |
| ✅ `true` | `&&` | ❌ `false`| ❌ `false` |
| ❌ `false`| `&&` | ✅ `true` | ❌ `false` |
| ❌ `false`| `&&` | ❌ `false`| ❌ `false` |


### B. Logical OR (`||`)
Think of `||` (typed using the vertical bar key above your Enter key) as a relaxed boss. As long as just *one* rule is met, you are good!

**Real-world example:** To get a discount at a store, you must be a Student **OR** a Senior Citizen. 

**Visual Truth Table:**
| Condition 1 | Operator | Condition 2 | Result |
| :---: | :---: | :---: | :---: |
| ✅ `true` | `\|\|` | ✅ `true` | **✅ `true`** |
| ✅ `true` | `\|\|` | ❌ `false`| **✅ `true`** |
| ❌ `false`| `\|\|` | ✅ `true` | **✅ `true`** |
| ❌ `false`| `\|\|` | ❌ `false`| ❌ `false` |


## C. Logical NOT (`!`)
The `!` operator is the "Opposite Day" operator. It only takes *one* condition and flips it.

**Visual Truth Table:**
| Condition | Operator | Result |
| :---: | :---: | :---: |
| ✅ `true` | `!` | ❌ `false` |
| ❌ `false`| `!` | ✅ `true` |
