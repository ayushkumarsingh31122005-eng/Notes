# 🚀 Deep Dive into the `java.lang` Package



Think of a **package** in Java like a folder on your computer that groups related files together. The `java.lang` package is the **default toolkit** provided by Java.

## 🌟 Why is `java.lang` Special?

In Java, if you want to use a tool from a specific package, you usually have to "import" it at the top of your code (e.g., `import java.util.Scanner;`). 

**The Magic Rule:** You **NEVER** have to import `java.lang`. Java automatically imports it into every single program you write. It is like the air your Java program breathes—it's always there!

## 1. The `Object` Class 🛠️
**What is it?** 
The `Object` class is the root or the "Grandparent" of every single class in Java. Even if you create a brand new class called `Dog`, Java secretly makes it a child of the `Object` class.

**Important Methods:**
*   `toString()`: Returns a text representation of the object.
*   `equals()`: Compares two objects to see if they are the same.

**Example Code:**
```java
class Dog {
    String name = "Buddy";
    
    // We can override the toString() method from the Object class
    public String toString() {
        return "This is a dog named " + name;
    }
}

public class Main {
    public static void main(String[] args) {
        Dog myDog = new Dog();
        // Even though we didn't write a print method, we can use toString()
        System.out.println(myDog.toString()); 
    }
}
```

---

## 2. Text Classes: `String`, `StringBuilder`, `StringBuffer` 🔤
**What are they?**
These classes handle text (sequences of characters). 
*   **String:** Once you create a `String`, you cannot change it (this is called being **immutable**).
*   **StringBuilder:** Used when you need to change, add, or delete parts of the text frequently (fast but not thread-safe).

**Example Code:**
```java
public class StringExample {
    public static void main(String[] args) {
        // Using String
        String greeting = "Hello";
        System.out.println("String length: " + greeting.length());
        
        // Using StringBuilder (Better for modifying text)
        StringBuilder builder = new StringBuilder("Java");
        builder.append(" is fun!"); // Adds to the end
        System.out.println(builder.toString()); // Output: Java is fun!
    }
}
```

---

## 3. The `Math` Class 🔢
**What is it?**
A utility class filled with mathematical formulas and operations. You don't need to create a `Math` object; you just use it directly.

**Example Code:**
```java
public class MathExample {
    public static void main(String[] args) {
        int a = 10;
        int b = 20;

        // Find the maximum of two numbers
        System.out.println("Maximum is: " + Math.max(a, b)); // Output: 20

        // Find the square root
        System.out.println("Square root of 25 is: " + Math.sqrt(25)); // Output: 5.0
        
        // Generate a random number between 0.0 and 1.0
        System.out.println("Random number: " + Math.random());
    }
}
```

---

## 4. The `System` Class 💻
**What is it?**
It connects your Java program to the computer system it is running on. You already know it from `System.out.println()`!

*   `System.out`: Standard output (your screen/console).
*   `System.in`: Standard input (your keyboard).
*   `System.currentTimeMillis()`: Gets the current time.

**Example Code:**
```java
public class SystemExample {
    public static void main(String[] args) {
        // Printing to the console
        System.out.println("Starting task...");

        // Getting current time in milliseconds
        long start = System.currentTimeMillis();
        
        // Stop the program immediately
        // System.exit(0); // If you uncomment this, the program dies here!
    }
}
```

## 5. Wrapper Classes 🎁
**What are they?**
Java has 8 simple, fast data types called **primitives** (like `int`, `double`, `boolean`, `char`). However, sometimes Java requires an **Object** (like when using Lists or Collections). Wrapper classes take a primitive and "wrap" it into an Object.

*   `int` -> `Integer`
*   `double` -> `Double`
*   `char` -> `Character`
*   `boolean` -> `Boolean`

**Example Code (Autoboxing and Unboxing):**
```java
public class WrapperExample {
    public static void main(String[] args) {
        // Primitive
        int basicNumber = 5;

        // Autoboxing: Java automatically wraps the primitive 'int' into an 'Integer' object
        Integer wrappedNumber = basicNumber;

        // Unboxing: Java automatically unwraps the object back to a primitive
        int unboxedNumber = wrappedNumber;

        // Using a Wrapper class method to convert text to a number
        int result = Integer.parseInt("100");
        System.out.println("Converted string to int: " + result);
    }
}
```
