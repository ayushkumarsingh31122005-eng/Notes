## 1. What is Control Flow in Java?

**Definition:** When you write a Java program, the computer reads your code from the top to the bottom, line by line. **Control Flow** is how we change this straight path. We can tell Java to "skip" some lines, "choose" between different lines, or "repeat" lines over and over.

**Real-Life Analogy:** Think of driving a car.
*   **Straight Line:** You drive straight down the road (Normal top-to-bottom code).
*   **Decision (if-else):** You reach a fork in the road. If the light is green, you go left. If it is red, you stop.
*   **Loop (for/while):** You are going around a roundabout 3 times before taking the exit.

**Visual Diagram:**

```
Start
  |
  V
[ Condition? ] ----(Yes)----> [ Run Code Block A ]
  |                                 |
 (No)                               |
  |                                 V
[ Run Code Block B ] ---------> ( Continue )
```

### Control Flow Coding Example:

Here is how we write decisions (`if-else`) and loops (`for`) in Java:

```java
public class ControlFlowExample {
    public static void main(String[] args) {
        
        // 1. Decision Making (if-else)
        int studentScore = 85;
        
        if (studentScore >= 50) {
            System.out.println("Congratulations, you passed!");
        } else {
            System.out.println("Sorry, you failed. Try again.");
        }

        // 2. Looping (for loop)
        // This will repeat the code 3 times
        System.out.println("Let's count to 3:");
        for (int i = 1; i <= 3; i++) {
            System.out.println("Number: " + i);
        }
    }
}
```

## 2. Multi-user, Multitasking, and Multithreading

Now that we know how a single program flows, what happens when a computer runs *many* things? Let's clarify these similar-sounding words.

### A. What is a Multi-user System?
**Definition:** A multi-user system allows multiple different human users to access and use the same computer or server at the exact same time.
**Analogy:** A **Public Library**. Many people walk in, read different books, and share the space simultaneously.

### B. What is Multitasking?
**Definition:** Multitasking is when a single user makes the computer perform multiple programs (tasks) at the same time. The Operating System switches between them very fast.
**Analogy:** **You in your room**. You are eating a snack, listening to Spotify, and typing an essay on Word all at the same time.

### C. What is Multithreading? (Very Important for Java)
**Definition:** Multithreading happens *inside* one single program. It means dividing one program into smaller, independent sub-tasks called **Threads**. 
**Analogy:** A **Restaurant Kitchen**. The whole kitchen working on one big family order is the "Program". Chef 1 is chopping vegetables (Thread 1), Chef 2 is boiling pasta (Thread 2), and Chef 3 is making the sauce (Thread 3). They work simultaneously on one main job.

## 3. Deep Dive: What exactly is a "Thread"?

**Definition:** A Thread is the smallest unit of processing that can be scheduled by an operating system. Think of it as a single "worker" inside your program. Every Java program has at least one thread (called the **Main Thread**), but you can create more!

### The Thread Lifecycle (How a Thread lives and dies)

A thread goes through different stages in its life, just like a butterfly!

**Visual Diagram:**

```
 [ NEW ] ---------> [ RUNNABLE ] <--------> [ RUNNING ]
(Created)           (Ready to run)          (Executing)
                          ^                      |
                          |                      V
                          +---- [ BLOCKED / WAITING ]
                                  (Paused/Sleeping)
                                         |
                                         V
                                     [ DEAD ]
                                  (Task Finished)
```

1.  **New:** You created the thread, but it hasn't started working yet.
2.  **Runnable:** The thread is ready and waiting for the CPU (the computer's brain) to give it attention.
3.  **Running:** The thread is actively executing its code!
4.  **Blocked/Waiting:** The thread is paused (maybe it's sleeping, or waiting for a file to download).
5.  **Dead:** The thread has finished its `run()` method and is gone.

## 4. Multithreading in Java (Coding Example)

Let's use our Control Flow loops from earlier inside two separate Threads. Imagine we are building a media player. We need one thread to play the video and another thread to play the audio at the same time.

### The Java Code:

```java
// 1. Create the Audio Thread
// We use 'extends Thread' to tell Java this class is a worker (Thread)
class AudioThread extends Thread {
    // The run() method is the engine. Control flow happens here!
    public void run() {
        for (int i = 1; i <= 3; i++) { // Loop control flow
            System.out.println("Audio: Playing song track " + i);
            try { 
                Thread.sleep(1000); // Wait 1 second (Moves to BLOCKED state)
            } catch (Exception e) {} 
        }
    } // Thread dies when this block finishes
}

// 2. Create the Video Thread
class VideoThread extends Thread {
    public void run() {
        for (int i = 1; i <= 3; i++) { // Loop control flow
            System.out.println("Video: Showing video frame " + i);
            try { 
                Thread.sleep(1000); // Wait 1 second
            } catch (Exception e) {} 
        }
    }
}

// 3. The Main Class to run our application
public class MediaPlayer {
    public static void main(String[] args) {
        System.out.println("--- Starting Media Player ---");
        
        // Step 1: NEW state
        AudioThread audio = new AudioThread();
        VideoThread video = new VideoThread();
        
        // Step 2 & 3: RUNNABLE to RUNNING state
        // Start them at the SAME TIME using .start()
        audio.start();
        video.start();
    }
}
```

### Explanation of the Syntax:

*   `extends Thread`: This turns a normal class into a mini-task worker.
*   `public void run()`: Whatever code (and control flow loops!) you put inside here is what the thread will actually do.
*   `Thread.sleep(1000)`: This pushes the thread into the **Blocked/Waiting** state for 1 second.
*   `audio.start()`: This is the magic button! It tells Java to create a new thread and execute the `run()` method in the background.
