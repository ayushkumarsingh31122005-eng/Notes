# Master Linked Lists: 


Think of a Linked List like a **passenger train**.

* A train is made up of multiple carriages.
* Each carriage carries people (Data).
* Each carriage is hooked to the next carriage (Link/Pointer).
* If you want to add a new carriage in the middle, you just unhook two carriages, insert the new one, and hook them back together. You don't have to move the entire train!

## 1. What is a Linked List?

A Linked List is a linear data structure. However, unlike Arrays, the elements in a Linked List are **not** stored right next to each other in the computer's memory. Instead, they are scattered randomly.

To keep track of where everything is, each element (called a **Node**) holds two things:

1. **Data:** The actual value (like a number, text, etc.).
2. **Next Pointer:** A reference (or memory address) pointing to the next Node in the line.

### Visual Diagram: Singly Linked List

Here is what a simple Linked List looks like in memory:

```text
       Head (Start)                                          Tail (End)
      +---------+---------+    +---------+---------+    +---------+---------+
      | Data: 10| Next: --|--->| Data: 20| Next: --|--->| Data: 30| Next:Null|
      +---------+---------+    +---------+---------+    +---------+---------+
```

* **Head:** The very first node. If you lose the Head, you lose the whole list!
* **Tail:** The last node. Its "Next" pointer points to `null` (meaning nothing comes after it).
* **Null:** In Java, `null` signifies the end of the list.

## 2. Why use Linked Lists instead of Arrays? (Interview Question!)

Top companies love to ask: *"Why choose a Linked List over an Array?"*

**The Array Problem:**
Arrays have a fixed size. If you have an array of 5 items and want to insert an item at the beginning, you have to physically shift all 5 items one step to the right. This takes a lot of time ($O(N)$ time complexity).

**The Linked List Solution:**
Linked Lists can grow or shrink dynamically. If you want to insert a node at the beginning, you just create the node and point it to the current Head. No shifting required! ($O(1)$ time complexity).

## 3. The Building Block: Creating a Custom Node in Java

Let's write the Java code for a single "train carriage" (Node). This is what you will write in an interview when asked to build one from scratch.

```java
// This is the blueprint for a single Node
class Node {
    int data;      // This holds the actual information (e.g., a number)
    Node next;     // This holds the address to the next Node

    // Constructor to create a new Node
    public Node(int data) {
        this.data = data;
        this.next = null; // When first created, it doesn't point to anything
    }
}
```

## 4. Building the Custom Linked List & Core Operations

```java
class CustomLinkedList {
    Node head; // The start of our list

    // OPERATION 1: Insert a new node at the END of the list
    public void insertAtEnd(int data) {
        Node newNode = new Node(data);

        // Case A: If the list is completely empty
        if (head == null) {
            head = newNode;
            return;
        }

        // Case B: If the list has nodes, we must travel to the end
        Node current = head; 
        while (current.next != null) {
            current = current.next;
        }
        current.next = newNode;
    }

    // OPERATION 2: Insert at the BEGINNING (Very fast!)
    public void insertAtStart(int data) {
        Node newNode = new Node(data);
        newNode.next = head; 
        head = newNode;      
    }
}
```

## 5. The Easy Way: Java's Built-in LinkedList

In real-world Java projects, you don't always build a Linked List from scratch. Java provides a ready-made one in the `java.util` package. 

*Note for FAANG:* Under the hood, Java's built-in `LinkedList` is actually a **Doubly Linked List** (nodes point forward AND backward).

### A. How to Initialize a built-in LinkedList

To create a built-in LinkedList, you must first import it, and then declare what *type* of data it will hold using angle brackets `< >`. 

```java
import java.util.LinkedList; // Step 1: Import it

public class Main {
    public static void main(String[] args) {
        
        // Step 2: Initialize it
        // Syntax: LinkedList<DataType> name = new LinkedList<>();
        
        // Example: A LinkedList that holds Integers
        LinkedList<Integer> numbers = new LinkedList<>();
        
        // Example: A LinkedList that holds Strings (Words)
        LinkedList<String> trainCars = new LinkedList<>();
    }
}
```
*Pro-Tip:* You cannot use primitive types like `int` or `double` inside the `< >`. You must use their Object Wrappers: `Integer`, `Double`, `Character`, `Boolean`.

### B. Different Methods of Java LinkedList

Java gives you tons of built-in methods so you don't have to write the while-loops yourself! Here are the most important ones:

| Method Name | What it does | Time Complexity |
| :--- | :--- | :--- |
| `add(Element e)` | Adds an item to the very END of the list. | $O(1)$ |
| `addFirst(Element e)` | Adds an item to the very BEGINNING of the list. | $O(1)$ |
| `add(int index, Element e)` | Inserts an item at a specific position. | $O(N)$ (Has to travel there) |
| `removeFirst()` | Removes and returns the first item. | $O(1)$ |
| `removeLast()` | Removes and returns the last item. | $O(1)$ |
| `get(int index)` | Retrieves the item at a specific position. | $O(N)$ |
| `size()` | Returns the total number of items in the list. | $O(1)$ |
| `contains(Object o)`| Returns `true` if the item exists in the list. | $O(N)$ |

### Example Code: Playing with Methods

```java
import java.util.LinkedList;

public class LinkedListMethodsDemo {
    public static void main(String[] args) {
        
        LinkedList<String> playlist = new LinkedList<>();
        
        // 1. ADDING items
        playlist.add("Song A"); // Adds to end
        playlist.add("Song B");
        
        // 2. ADDING to specific spots
        playlist.addFirst("Intro Song"); // Puts at the start
        playlist.add(2, "Middle Song");  // Inserts at index 2
        
        System.out.println(playlist); 
        // Output: [Intro Song, Song A, Middle Song, Song B]
        
        // 3. GETTING items
        String currentlyPlaying = playlist.get(1); // Gets "Song A"
        System.out.println("Playing: " + currentlyPlaying);
        
        // 4. REMOVING items
        playlist.removeLast(); // Removes "Song B"
        
        // 5. CHECKING size
        System.out.println("Total songs: " + playlist.size()); // Output: 3
    }
}
```

## 6. Time & Space Complexity (FAANG Focus)

To crack Google or Microsoft, remember:
* **Accessing by index (`get(2)`)** in a Linked List is $O(N)$ because the computer must walk from the Head, node by node, to reach the index. An Array can do this in $O(1)$.
* **Inserting at the Head (`addFirst()`)** is $O(1)$. An Array does this in $O(N)$ because it has to shift everything.

## 7. FAANG Interview Secret Weapon: The "Two Pointer" Technique

In advanced interviews, they will ask you to solve puzzles with custom Linked Lists. The most famous pattern is the **"Tortoise and Hare"** (Fast and Slow pointers).
* The Slow pointer moves 1 step at a time.
* The Fast pointer moves 2 steps at a time.
* **Why?** When the Fast pointer reaches the end, the Slow pointer will be exactly in the middle! It also helps detect if a list is accidentally trapped in an infinite loop (a cycle).
