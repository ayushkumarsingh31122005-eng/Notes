# Master Stacks: 


In top tech interviews (like Google or Microsoft), Stacks are the secret weapon for solving puzzles related to undo mechanisms, checking if brackets are balanced `() {} []`, and navigating mazes.

## 1. What is a Stack?

A Stack is a linear data structure that follows a very strict rule called **LIFO**.

* **LIFO** stands for **Last In, First Out**.
* The **Last** item you put into the stack is the **First** one you take out.

**Real-world examples:**
1. A stack of plates: You add plates to the top, and you take plates off the top. You never pull a plate from the bottom!
2. The "Undo" button (Ctrl+Z) on your computer: The last typing mistake you made is the first one that gets undone.
3. Your browser's "Back" button: The last page you visited is the first one you go back to.

## 2. The 4 Core Operations

Whether you use Java's built-in Stack or build your own, these are the methods you will use 99% of the time:

1. **`push(item)`**: Puts an item on the very top of the stack.
2. **`pop()`**: Removes the item at the very top and returns it to you.
3. **`peek()`** (or `top()`): Looks at the item on the very top *without* removing it.
4. **`isEmpty()`**: Returns `true` if the stack has nothing in it, `false` otherwise. (Always check this before popping!)

*Note: All of these operations are extremely fast. They have an $O(1)$ Time Complexity.*

## 3. Using Java's Built-in Stack Class

Java has a built-in `Stack` class that is very easy to use. Here is the syntax and an example.

```java
import java.util.Stack; // Step 1: Import the Stack class

public class StackDemo {
    public static void main(String[] args) {
        
        // Step 2: Initialize it (Syntax is just like LinkedList!)
        // Stack<DataType> name = new Stack<>();
        Stack<String> webHistory = new Stack<>();
        
        // Let's browse the web (Pushing items)
        webHistory.push("google.com");
        webHistory.push("youtube.com");
        webHistory.push("github.com");
        
        System.out.println("Current Stack: " + webHistory);
        // Output: [google.com, youtube.com, github.com]
        
        // What is the current page we are on? (Peeking)
        String currentPage = webHistory.peek();
        System.out.println("Currently viewing: " + currentPage); 
        // Output: github.com
        
        // Let's click the Back Button (Popping)
        String removedPage = webHistory.pop();
        System.out.println("We just left: " + removedPage); // Output: github.com
        System.out.println("Now we are back on: " + webHistory.peek()); // Output: youtube.com
    }
}
```

## 4. 🚨 FAANG Interview Secret: The "Deque" Gotcha 🚨

**Pay close attention to this section, as it separates beginners from senior candidates in interviews!**

While Java has a `Stack` class, **professional Java developers rarely use it today.** Why? 
Because the legacy `Stack` class in Java was built a long time ago. It is "synchronized," which means it has extra safety features for multi-threading that make it very slow in normal programs.

If a FAANG interviewer asks you to use a built-in stack, they will be highly impressed if you use the modern alternative: **ArrayDeque** (pronounced "Deck").

An `ArrayDeque` can act exactly like a Stack, but it is much faster.

### The Modern Way to Code a Stack in Java:
```java
import java.util.ArrayDeque;
import java.util.Deque;

public class ModernStack {
    public static void main(String[] args) {
        // Initialize a Stack the modern, fast way
        Deque<Integer> stack = new ArrayDeque<>();
        
        // The methods are exactly the same!
        stack.push(100);
        stack.push(200);
        
        System.out.println(stack.pop()); // Removes and prints 200
    }
}
```

## 5. Building a Custom Stack (Interview Preparation)

In a top-tier interview, they might say: *"Don't use Java's built-in tools. Build a Stack from scratch."* 

You can build a Stack using an Array or a Linked List! Let's build a simple one using an Array.

```java
class CustomStack {
    int[] arr;
    int top; // This keeps track of the index of the top item
    int capacity;

    // Constructor to initialize the stack
    public CustomStack(int size) {
        this.capacity = size;
        this.arr = new int[capacity];
        this.top = -1; // -1 means the stack is totally empty
    }

    // Push Operation
    public void push(int data) {
        if (top == capacity - 1) {
            System.out.println("Stack Overflow! The stack is full.");
            return;
        }
        top++; // Move the pointer up
        arr[top] = data; // Place the data
    }

    // Pop Operation
    public int pop() {
        if (top == -1) {
            System.out.println("Stack Underflow! Nothing to pop.");
            return -1; // Or throw an exception
        }
        int poppedItem = arr[top];
        top--; // Move the pointer down
        return poppedItem;
    }
}
```

## 6. Where are Stacks used in FAANG Interviews?

If you see these keywords in a coding problem, your brain should immediately think **"I need a Stack!"**:

1. **"Reverse"**: Stacks naturally reverse things. Put "A", "B", "C" in, and you get "C", "B", "A" out.
2. **"Balanced Brackets/Parentheses"**: A classic interview question. (e.g., matching `{ [ ( ) ] }`). You push open brackets, and pop when you see a closing bracket to ensure they match.
3. **"Next Greater Element"**: Finding the next highest temperature in an array of daily temperatures.
4. **"Depth First Search (DFS)"**: When searching through a tree or a graph maze, a Stack helps you remember where you came from so you can backtrack if you hit a dead end.

## 7. Time & Space Complexity

* **Push:** $O(1)$ (Constant time - instant)
* **Pop:** $O(1)$ (Constant time - instant)
* **Peek:** $O(1)$ (Constant time - instant)
* **Space Complexity:** $O(N)$ where $N$ is the number of items you store in the stack.
