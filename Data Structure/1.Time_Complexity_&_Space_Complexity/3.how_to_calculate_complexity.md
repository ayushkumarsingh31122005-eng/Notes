# 🧮 How to Calculate Time and Space Complexity

Welcome back! As your DSA teacher, I am thrilled to see you taking this next step. Knowing *what* complexity is important, but knowing *how to calculate it* is your superpower for coding interviews at Google, Microsoft, and Facebook.

In interviews, we use **Big-O Notation** (like $O(N)$). It describes the "worst-case scenario"—how your code behaves when the data gets HUGE. 

Let's learn the simple rules to calculate this for any Java code.

---

## Part 1: The Golden Rules of Calculation

Before we look at code, you must memorize these two rules for Big-O notation. Interviewers expect you to apply these automatically:

### Rule 1: Drop the Constants
If your code takes $O(2N)$ steps, we drop the '2' and just call it $O(N)$. 
*Why?* Because as $N$ becomes 1 million, the '2' doesn't change the *shape* of the line on a graph. We only care about the trend.

### Rule 2: Drop the Non-Dominant Terms
If your code's time is $O(N^2 + N)$, we drop the $N$ and just keep $O(N^2)$.
*Why?* If $N$ is 1,000, then $N^2$ is 1,000,000. The extra 1,000 (the $N$) is so small it doesn't matter. Always keep the biggest, slowest term.

---

## Part 2: Calculating Time Complexity

To calculate time complexity, we **count the number of operations or loops** relative to the input size ($N$).

### 1. Constant Time: $O(1)$
This happens when there are **no loops** depending on the input size. It takes the same time whether the array has 10 items or 10 million items.

```java
public class ComplexityCalc {
    // Input: an array of size N
    public void printFirstItem(int[] arr) {
        // We only do ONE operation. It does not loop.
        System.out.println(arr[0]); 
    }
}
```
*   **Calculation:** 1 operation = $O(1)$. Very fast!

### 2. Linear Time: $O(N)$
This happens when you have **one loop** going through your data.

```java
public class ComplexityCalc {
    public void printAllItems(int[] arr) {
        int n = arr.length;
        
        // This loop runs N times.
        for(int i = 0; i < n; i++) {
            System.out.println(arr[i]); // Executes N times
        }
    }
}
```
*   **Calculation:** The loop runs $N$ times. Total time = $O(N)$.

### 3. Quadratic Time: $O(N^2)$
This happens when you have a **loop inside a loop (nested loops)**, and both depend on the input size $N$. 

```java
public class ComplexityCalc {
    public void printPairs(int[] arr) {
        int n = arr.length;
        
        // Outer loop runs N times
        for(int i = 0; i < n; i++) {
            
            // Inner loop runs N times FOR EVERY outer loop step
            for(int j = 0; j < n; j++) {
                System.out.println(arr[i] + " and " + arr[j]);
            }
        }
    }
}
```
*   **Calculation:** $N$ (outer loop) $\times$ $N$ (inner loop) = $N \times N = N^2$. Total time = $O(N^2)$.
*   *Interview Tip:* Google and Microsoft interviewers will almost always ask you to optimize an $O(N^2)$ solution into something faster!

### Visualizing Time Complexity Growth
```text
Fastest (Best) -----------------------------------------> Slowest (Worst)
$O(1)$       $O(\log N)$       $O(N)$       $O(N \log N)$       $O(N^2)$
Constant     Logarithmic    Linear       Log-Linear          Quadratic
```

## Part 3: Calculating Space Complexity

Remember our previous lesson: **Total Space = Input Space + Auxiliary (Extra) Space**. In interviews, we usually calculate the **Auxiliary Space** (the new variables and data structures you create).

To calculate it, look for the `new` keyword or extra variables in your Java code.

### 1. Constant Space: $O(1)$
You only create a few simple variables (like `int`, `boolean`), regardless of the input size.

```java
public class SpaceCalc {
    public int findMax(int[] arr) {
        int max = arr[0]; // 1 variable (O(1) space)
        
        for(int i = 0; i < arr.length; i++) { // 1 variable 'i' (O(1) space)
            if(arr[i] > max) {
                max = arr[i];
            }
        }
        return max;
    }
}
```
*   **Calculation:** We created `max` and `i`. That is 2 memory slots. Since 2 is a constant, we drop it (Rule 1). Total extra space = $O(1)$.

### 2. Linear Space: $O(N)$
You create a **new data structure** (like an array, list, or hash map) whose size depends on the input size $N$.

```java
public class SpaceCalc {
    public int[] createEvensArray(int n) {
        // We are creating a NEW array of size N
        int[] evens = new int[n]; 
        
        for(int i = 0; i < n; i++) {
            evens[i] = i * 2;
        }
        
        return evens;
    }
}
```
*   **Calculation:** `new int[n]` creates $N$ new memory slots. Total extra space = $O(N)$.

## 🏆 Checklist for FAANG Interviews
When looking at your code, ask yourself these 3 questions:
1. **Time:** How many times do my loops run based on the input size $N$? Do I have loops inside loops?
2. **Space:** Did I use the `new` keyword to create arrays or objects? Does the size of this new memory grow as $N$ grows?
3. **Rules:** Did I drop the constants (e.g., $O(2N) \rightarrow O(N)$) and non-dominant terms?
